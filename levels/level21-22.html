A cronjob is a schedular that works like this
*    *    *    *    *   /home/user/bin/somecommand.sh
|    |    |    |    |            |
|    |    |    |    |    Command or Script to execute
|    |    |    |    |
|    |    |    | Day of week(0-6 | Sun-Sat)
|    |    |    |
|    |    |  Month(1-12)
|    |    |
|    |  Day of Month(1-31)
|    |
|   Hour(0-23)
|
Min(0-59)
So * * * * * bandit22 /usr/bin/cronjob_bandit22.sh &> /dev/null 
A * means that it will run at every interval mentioned, so this script runs every minute, of every hour, of every day, of every month. 

Now the job is running a script called /usr/bin/cronjob_bandit22.sh \\ reading it shows
#!/bin/bash
chmod 644 /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv
cat /etc/bandit_pass/bandit22 > /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv

chmod 644 sets file permission so that the owner can read and write the file while the group and all others can only read it

so every minute, cronjob_bandit22 will run a command that sets the perms for /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv to be readable by all others, then sends the output of /etc/bandit_pass/bandit22 to /tmp/t7O6lds9S0RqQh9aMcz6ShpAoZKF7fgv
